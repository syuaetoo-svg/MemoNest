> B2 实现追踪：本文件保留第二阶段 A 的历史设计范围；当前身份、记录与授权实现及未验证边界见 [核心全栈说明](CORE_FULLSTACK.md)。

## 1. 品牌与角色

品牌：MemoNest｜AI 角色陪伴式生活手帐。关键词是温暖、精致、轻量、可控制。陪伴感用温和语气与留白表达，不用羞辱、连签断档、角色哭诉催留存。

小栖是一位原创虚构 AI 整理伙伴。当前页面用植物图标作为识别，不把它声称为已完成角色立绘。未来需单独创作角色轮廓、表情与插图，保留创作来源与授权记录；不临摹竞品插画。

文案表达事实而非替用户命名情绪：“要不要把这段话整理成记录？”而非“我知道你今天一定很难过”。不宣称永久守护、真实人类感情或心理治疗能力。

## 2. 现有设计 token 与后续约束

以下颜色取自 `src/app/globals.css`，是已实现事实。

| Token | HEX | 用途与约束 |
| --- | --- | --- |
| paper | `#F7F5EF` | 页面底色 |
| surface | `#FFFEFA` | 卡片、输入容器 |
| ink | `#303E35` | 主要正文 |
| muted | `#657068` | 次要正文，不用低透明度削弱必要说明 |
| line | `#E5E8DF` | 装饰边界；不能独自表达输入状态 |
| sage / sage-dark | `#9BB39C` / `#3E6249` | sage 用装饰；深绿用于主动作和文字 |
| sage-light | `#EAF0E6` | 次要背景、导航选中 |
| clay / clay-light | `#A5664D` / `#F5E9E0` | 温暖提示背景；小号关键文字用 ink，避免未经检查的陶土色对比 |

未来状态色建议：错误文字 `#8A3030`、错误底 `#FBECEC`；成功用 sage-dark 加文字/图标，不只改变颜色。输入可用状态边界提案 `#7B877D`，用于替换只靠 line 的控件边界；当前禁用页面不改。本次只记录规范，后续启用表单时实施。

字体沿用系统栈 Arial、PingFang SC、Microsoft YaHei、sans-serif，不加载远程字体。正文基准 16px/1.7，字段/辅助说明至少 14px/1.6；12px 只用于非关键元信息，不能用于长期记忆授权的重要含义。标题移动端 28–36px、桌面 36–48px，避免超长中文单行。

间距采用 4px 基础倍数：8（图标与字）、12（组内）、16（字段）、24（卡片）、32/48（区块）。移动内容边距 20px，卡片 24px；卡片圆角 24px，主按钮 14px、输入 12px。圆角服务层级，不把每个元素做成大胶囊。

## 3. 手机优先布局

- 支持 320px 起不横向滚动；主要设计帧 390px，复查 320/375/768/1280。
- 小于 768px 单列；页头品牌与导航分两行，导航目标未来最少 44×44px。保持当前四个目的地，不额外加一排功能图标。
- 768px 以上角色介绍与聊天、记录表单与提示可双列；桌面内容最大约 1152px，长正文最大 65 个字符宽度，避免大屏拉长阅读。
- 聊天输入考虑软键盘与安全区，未来使用 `dvh`/安全区内边距并实机验证，不用固定 `100vh` 假设可见高度。
- 保留输入上下文：提示卡不能使滚动自动跳到最底；只有用户已在底部时跟随新回复。
- 原型可考虑移动底部导航，但它是待测试变体，不宣称已替换现有顶部导航。

## 4. 组件规格

| 组件 | 主要变体 / 行为 | 验收要求 |
| --- | --- | --- |
| AppShell / Navigation | 四目的地、当前页高亮 | `aria-current`，图标辅以文字，键盘可达 |
| PageHeading / Card | 页面标题、区块卡片 | 标题层级正确，不让装饰卡充当按钮 |
| Button / Field | 主、次、危险、禁用、提交中 | 可用/禁用原因可读；提交中防重复；标签不以 placeholder 替代 |
| CharacterProfile | 小栖介绍、AI 标识、可跳过 | 不暗示人类身份，多角色未上线不制造假选项 |
| MessageBubble / Composer | 用户/AI、生成/失败/停止 | 错误可重试，逐字流式不反复抢屏幕阅读焦点 |
| SuggestionCard | 未保存、查看、忽略 | 标来源；不抢焦点；不能看起来像已保存记忆 |
| CandidateEditor | 原文/候选、日期确认、放弃 | 标记未知字段；编辑用户主导；只存确认版本 |
| SaveReceipt / UndoNotice | 保存状态、10 秒撤销、详情兜底 | `aria-live=polite`；超时仍可删；不要求用户追逐 toast |
| MemoryPermissionSheet | 具体摘要、角色、用途、版本、确认 | 默认不授权，取消与确认均清楚；单独后置于私人保存 |
| JournalCard / Timeline | 日期、标题/摘要、标签、来源 | 空标题使用正文首句展示，不强制用户补写 |
| MemoryCard | 角色范围、源记录、授权状态、撤回 | 与私人记录卡有不同文字标识，不能只用颜色区分 |
| FilterBar / ReviewSource | 日期、关键词、来源跳转 | 清条件、无结果解释；故事引用可逐条打开 |
| ConfirmDialog | 撤回/删记录/删聊天/清角色记忆 | 标清对象、范围与后果；焦点锁定/返回 |

已有可复用实现是 Navigation、PageHeading、Card、FeatureLink、EmptyState、PhaseNotice；其余属于未来组件清单，不是当前组件代码。

## 5. 空、加载、错误和成功

| 场景 | 内容规格 | 后续行为 |
| --- | --- | --- |
| 首次聊天 | “开始分享一个片刻”，标 AI 身份 | 不预置用户虚构聊天；当前阶段继续显示未开放 |
| 无私人记录 | “还没有保存的生活记录” | 去记录，不显示模拟数量 |
| 无角色记忆 | “你尚未授权小栖使用任何长期记忆” | 解释私人记录仍可存在，不强制授权 |
| 筛选无结果 | 显示当前条件 | 清筛选，不生成一个相似事件冒充结果 |
| 提取中 | “正在整理你选中的消息” | 可停止，不写库 |
| 保存失败 | “未保存，请重试” | 保留当前页面输入、不要显示成功图标 |
| 撤回失败 | “撤回尚未确认” | 重试并检查服务器状态，不能承诺已忘记 |
| 版本冲突 | “原记录已改变，请重新确认” | 新版本预览；旧授权不能继续使用 |
| 成功保存 | “已保存给你自己，尚未授权角色使用” | 10 秒撤销 + 详情链接；长期授权后置 |

## 6. 隐私授权和内容层级

权限层次不能折叠成一个“同意隐私条款”按钮：

1. 使用真实 AI 前：说明当次输入与选定上下文会被模型服务处理；拒绝可手写。
2. 开启建议前：明确本会话分析范围，可随时关闭，与长期记忆无关。
3. 保存私人记录：展示最终正文与日期；只写自己的记录库。标明以后主动要求 AI 回顾时，会再说明当次处理。
4. 可选角色长期记忆：窗口结束后另开面板，显示摘要、角色范围和撤回路径；默认不授权。
5. 删除/撤回：解释原文、派生记忆、历史生成内容与备份的不同边界，详细策略见 [架构](ARCHITECTURE.md)。

示例授权文案：“允许小栖在后续聊天中按需使用下面这条摘要。仅限小栖，持续到你撤回、删除或修改来源。私人记录其他内容不会因此自动进入长期记忆。”此为未来文案，不代表已实现服务承诺。

## 7. 无障碍、可读性与反馈

目标 WCAG 2.2 AA：普通文字对比至少 4.5:1、大字 3:1；可用控件边界与焦点至少 3:1，装饰 line 不够表示输入状态。实际比值需测量，不能因配色温暖宣称达标。弱化文字仍须可读。

全部操作支持键盘，跳过导航入口、可见 focus、正确 landmark 与 h1；图标按钮有可访问名称。模态 Esc/返回可关闭、恢复焦点；禁用控件旁解释原因。`prefers-reduced-motion` 用户不展示装饰动画，动效建议 150–200ms，不用心跳/关系倒计时催促。

触控目标至少 44×44px；200% 缩放及字体放大不丢关键按钮。AI 流式输出按句/完成后通知，避免字符级 `aria-live` 噪声。错误与授权变化通过文字和状态提示同步，不仅依赖 toast。

本阶段按 sRGB 相对亮度公式计算 token 颜色对比（不是浏览器截图或全面审计）：ink/paper 10.32:1、muted/paper 4.73:1、white/sage-dark 6.89:1、拟定可用字段边界/paper 3.44:1。前三组达到普通文字 4.5:1 的颜色门槛，字段边界达到 3:1；只覆盖这些指定颜色组合，不代表所有状态、字号和控件已合规。

以上为上线前要求；本阶段没有执行屏幕阅读器、实机软键盘或 WCAG 全面审计。
